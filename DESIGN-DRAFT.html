Design reference — status of every decision

Locked (your approvals, wired into Part M3): left section rail · ribbon on top in captioned groups · floating quick toolbar · layout switcher (Ribbon / Studio / Focus — try it in the title bar above) · hero start screen (logo + six shortcuts) · document tabs in the title bar · Ctrl+K command search · collapsible Pages and Annotations panels (chevron in each header collapses; the slim edge handle reopens — try both) · panel-tab strip on the document panel (six panels, one at a time) · Studio opens the active section's tools as a temporary overlay (click a rail section while in Studio — capability parity with Ribbon mode) · Focus keeps the title bar and suspends panel reopen handles · contrast by **live derivation**: this mockup computes accent-text / accent-solid / on-accent / page-accent / thumb-ring at load and on every theme switch via `onColor(brand, real background, required ratio)` — one stored brand color per theme, nothing hand-picked, exactly the M2 root rule (view source: `deriveAccents()`) · full conformance to the M2/M4 scales (fonts 10/11/12/13/14/16/20+display, icons 12/14/16/20, even spacing) · 24 px panel tabs. The fake document ink inside pages/thumbnails (gray bars, yellow highlight) is content art, not chrome — token and scale rules deliberately do not apply to it, nor to the placeholder logo artwork.

a
Placeholder branding. The leaf logo and wordmark here are stand-ins only — the final logo is a design the user will supply to the building agent (Part M8). Nothing brand-related in this draft is final.
b
Standing defaults, object if you disagree: accent #16a34a light / #2fb96a dark · compact density (32 px controls) · 6–7 px corners · canvas deep-neutral dark / soft-gray light · theme follows the OS · high-contrast as a third full theme (toggle above).
c
Empty states are drawn, not implied: the Annotations panel and the zero-recents start screen (toggle "Recents: empty" above) show the pattern every surface must follow (M5).
d
This mockup's markup is illustrative only. The real app is composed from the primitive set with design tokens (Part M2/M4); nobody should treat this HTML as reference code.
