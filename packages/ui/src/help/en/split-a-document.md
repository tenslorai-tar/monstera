Split writes several new PDFs from one document: one for each page, or one for each range you type. This document is not changed.

## Steps

1. In the rail, choose **Organize**, then **Split…** in the **Combine** group.
2. Choose **One file for each page**, or **One file for each range** and type the **Ranges**, for example `1-3, 4-6`.
3. The window says how many files will be written. Choose **Choose a folder…** and pick the folder.

![The Split into several PDFs window with One file for each range and Ranges filled in](screenshot:split-a-document-1)

## Good to know

- Files are named after the document and their pages, for example "Report 4-9.pdf".
- Monstera checks every file name before writing any, and will not overwrite a file that is open in another tab.
