You can select the words on a page and copy them into another program.

## Steps

1. In the rail, choose **Home**, then **Text** in the **Quick tools** group (its full name is **Select text**).
2. Drag across the words you want. Double-click selects a word.
3. Press **Ctrl+C**, or right-click and choose **Copy**. **Copy** is also in **Edit**, **Text** group.

![Words selected on a page with the right-click menu showing Copy](screenshot:select-and-copy-text-1)

## Good to know

- If a page is only a picture (for example a scan), Monstera says **This page is a picture, so there is no text to select or search.** Recognise its text first; see "Make scanned pages searchable".
- Right-clicking selected text also lets you highlight it, comment on it, search for it, mark it for redaction, or ask the AI assistant about it.
