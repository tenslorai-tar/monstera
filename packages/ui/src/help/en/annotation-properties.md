The **Properties** tab of the right-hand panel controls how annotations look. With nothing selected, it sets how the next ones are drawn. With marks selected, it changes them.

## Steps

1. Open the **Properties** tab in the right-hand panel (or right-click a mark and choose **Properties**).
2. With nothing selected, the heading reads **New annotations**. Choose a **Colour**, **Opacity**, **Line width** and **Font size** for the next marks you draw.
3. To change existing marks, select them with **Select annotations**. Each change applies at once.
4. For a selected mark you can also change its **Author**, and its **Blend** (**Multiply** or **Normal**). **Created** shows when it was made.
5. Tick **Use as default for new annotations** to keep a selected mark's look for the next ones you draw.

![The Properties tab showing a selected highlight's colour swatches, opacity and blend](screenshot:annotation-properties-1)

## Good to know

- **Each tool's own** colour keeps each tool's usual colour, for example yellow for highlights.
- Some kinds of mark, such as highlights and notes, have no line width; the tab says so.
- Your name on new marks comes from **Settings**, **Editing defaults** page, **Your name for comments**. It is seen by anyone you share the document with. Empty means your Windows user name.
- The same defaults can be set with no document open in **Settings**, **Editing defaults** page.
- Changes can be undone with **Ctrl+Z**.
