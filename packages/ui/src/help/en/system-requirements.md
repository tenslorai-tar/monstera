Monstera runs on Windows 10 and Windows 11. Everything it needs to open, edit, convert and recognise documents is installed with it.

## What your computer needs

1. Windows 10 version 1809 or later, or Windows 11, 64-bit (x64). On Windows 11 on ARM it runs through Windows' own emulation.
2. About 400 MB of disk space for the download from the Microsoft Store, and more once it is installed.
3. Memory: 4 GB or more. Monstera uses about 360 MB with no document open, about 760 MB with seven documents open, and about 1.1 GB after an edit, measured on 14 October 2026. Large documents use more.

Nothing else needs to be installed first: not Microsoft Office, not a PDF reader, not a separate runtime. To check that every part of Monstera starts on your computer, choose **Components** in the **Help** menu, then **Verify files**.

## What optional features need

- **Cloud storage**, **DocuSign** and the **Assistant** need an internet connection. The assistant needs your own key from Anthropic or Azure, and DocuSign needs a DocuSign developer key.
- **Print** needs a printer set up in Windows. *Microsoft Print to PDF* counts as one. To add a printer, open Windows Settings, then Printers & scanners.
- **New PDF from camera** needs a camera. On an N or KN edition of Windows it also needs the Media Feature Pack: search Windows Settings for Optional features, add the Media Feature Pack, and restart the computer.
