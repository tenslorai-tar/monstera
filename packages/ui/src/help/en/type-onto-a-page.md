The Typewriter adds your text straight onto the page with no border, which is handy for filling in a printed form that has no fillable fields.

## Steps

1. In the rail, choose **Comment** (or **Edit**), then **Typewriter**.
2. Drag an area where the text should go.
3. In the **Typewriter** window, type in **Type onto the page**, then choose **Add text**.

![Typewriter text added on a form line, with the Typewriter window](screenshot:type-onto-a-page-1)

## Good to know

- Font size and colour come from the **Properties** tab. The font itself cannot be chosen yet.
- For text inside a bordered box, use "Add a text box".
- Undo with **Ctrl+Z**.
