Monstera never throws away your changes without asking. Closing a tab, pressing Ctrl+W, closing the window or quitting all ask first when a document has unsaved changes.

## Steps

1. Close the tab (its close button, ×, or **Ctrl+W**) or close the window.
2. The **Unsaved changes** window names the document. Choose:
   - **Save** to save the changes, then close;
   - **Don't save** to close and lose the changes;
   - **Cancel** to keep everything open.

![The Unsaved changes window naming the document, with Save, Don't save and Cancel](screenshot:close-with-unsaved-changes-1)

## Good to know

- When you quit with several changed documents, Monstera asks about each one in turn. Choosing **Cancel** at any of them keeps them all open.
- If the save does not work, the document stays open so you can save it somewhere else.
- A document with no unsaved changes closes without asking.
