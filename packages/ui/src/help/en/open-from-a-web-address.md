If you have a link to a PDF, Monstera can download it, save it where you choose and open it.

## Steps

1. In the rail, choose **Tools**, then **From URL…** in the **Create** group (**Open from web address…**).
2. Type or paste the **Address**; it must start with `https://`.
3. Choose **Open**, then choose where to save the file. It opens in a new tab.

![The Open a PDF from a web address window](screenshot:open-from-a-web-address-1)

## Good to know

- Only secure addresses (https) are opened, including any address the website sends Monstera on to.
- Addresses containing a user name or password, and addresses inside your own computer or network, are refused.
- If the address does not return a PDF, nothing is saved.
