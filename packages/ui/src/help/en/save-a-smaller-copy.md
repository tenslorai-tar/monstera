If a PDF is too large to email or upload, save a smaller copy. Monstera makes the pictures in it smaller and shows you the size before you save.

## Steps

1. In the rail, choose **Tools**, then **Compress…** in the **Convert** group (its full name is **Save a smaller copy…**).
2. In **Image quality**, choose **High**, **Medium** or **Low — the smallest file**.
3. Choose **Check the size**. Monstera shows the size now and the size of the copy.
4. If the copy is smaller, choose **Choose where to save…** and save it.

![The Save a smaller copy window showing the size now and the size of the copy](screenshot:save-a-smaller-copy-1)

## Good to know

- Only pictures are made smaller. Text, pages, comments and tags stay.
- If the copy would not be smaller, it is not saved.
- The open document is not changed, and you cannot save the copy over it.
- A password-protected document may not be readable for this; the message says so.
- If you change the document after checking the size, check again.
- If this copy of Monstera cannot make smaller copies, it says so.
