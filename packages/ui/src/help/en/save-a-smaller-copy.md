If a PDF is too large to email or upload, save a smaller copy. Monstera makes the pictures in it smaller and shows you the size before you save.

## Steps

1. In the rail, choose **Tools**, then **Compress…** in the **Convert** group (its full name is **Save a smaller copy…**).
2. In **Image quality**, choose **High**, **Medium** or **Low — the smallest file**.
3. Choose **Check the size**. Monstera shows the size now and the size of the copy.
4. If the copy is smaller, choose **Choose where to save…** and save it.

![The Save a smaller copy window showing the size now and the size of the copy](screenshot:save-a-smaller-copy-1)

## Make it fit a size you need

When a form or a mailbox takes files only up to a certain size:

1. In **Image quality**, choose **A size I choose**.
2. In **Size**, type the size, and choose **KB** or **MB** beside it. Monstera remembers the last size you typed.
3. Choose **Check the size**. Monstera tries its settings from the lightest to the strongest and keeps the lightest one that fits, so the pictures stay as sharp as that size allows.
4. Choose **Choose where to save…** and save it.

If the file cannot get that small, Monstera tells you the smallest it can go, with the pictures at their lowest quality, and you can still save that copy. Pictures are never made so small that they cannot be read.

## Good to know

- Only pictures are made smaller. Text, pages, comments and tags stay, so a file that is mostly text may not get much smaller.
- If the copy would not be smaller, it is not saved.
- The open document is not changed, and you cannot save the copy over it.
- A password-protected document may not be readable for this; the message says so.
- If you change the document after checking the size, check again.
- Checking a size can take a little longer than checking one quality, since Monstera may try several.
- If this copy of Monstera cannot make smaller copies, it says so.
