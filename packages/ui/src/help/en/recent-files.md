Monstera remembers the files you opened most recently so you can get back to them in one click.

## Steps

1. Close every tab, or start Monstera, to see the start screen.
2. Under **Recent**, choose a file. Each card shows when you opened it (for example **Today** or **Yesterday**) and which folder it is in.
3. To empty the list, choose **Clear list**.

![The Recent list on the start screen with three file cards and the Clear list button](screenshot:recent-files-1)

## Good to know

- Up to 10 files are listed.
- If a file has been moved or renamed since, Monstera says it could not be opened and removes it from the list.
- The small page pictures can be turned off: in **Settings**, on the **Privacy** page, turn off **Show previews of recent files**. Turning it off deletes the pictures already kept.
