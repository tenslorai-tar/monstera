Monstera remembers the ten files you opened most recently so you can get back to them in one click.

## Steps

1. Open the **File** menu and point to **Recent**. Every file Monstera remembers is listed there, newest first.
2. Choose a file to open it.
3. To empty the list, choose **Clear recent files** at the bottom of the submenu.

![File › Recent open, listing recent files with one marked Unavailable, and Clear recent files at the foot](screenshot:recent-files-2)

The start screen shows the four most recent of the same files under **Recent**. Each card shows when you opened it (for example **Today** or **Yesterday**) and which folder it is in, and **Clear recent files** above the cards empties the same list.

![The Recent list on the start screen with three file cards and the Clear recent files button](screenshot:recent-files-1)

## Good to know

- Monstera keeps your ten most recent files. Opening an eleventh forgets the oldest, and its picture with it. The start screen shows the latest four; **File** › **Recent** shows all ten.
- A file that is not where it was — moved, renamed, deleted, or on a drive that is not connected — stays in the list marked **Unavailable**, and cannot be opened from there. Connect the drive again and it can be opened as before. **Clear recent files** removes it.
- A file on a slow network drive shows **Checking…** while Monstera looks for it, so the list appears at once. It then shows as one you can open, or as **Unavailable**.
- After Monstera closed unexpectedly, the start screen offers to reopen the documents that were open. A document that is no longer where it was is left out of the offer.
- To open the documents you had open last time as soon as Monstera starts, turn on **Reopen my documents at start** in **Settings**, on the **Viewing** page.
- The small page pictures can be turned off: in **Settings**, on the **Privacy** page, turn off **Show previews of recent files**. Turning it off deletes the pictures already kept.
