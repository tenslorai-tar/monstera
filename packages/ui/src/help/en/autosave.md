If you want Monstera to save for you, turn on autosave. It is off unless you turn it on, because a save replaces the file on disk.

## Steps

1. Open **Settings** (in the rail, choose **Settings**).
2. Choose the **Saving** page.
3. In **Save automatically**, choose **Every minute**, **Every 5 minutes** or **Every 10 minutes**. Choose **Off** to stop.

![The Saving page of Settings with the Save automatically choices](screenshot:autosave-1)

## Good to know

- Only documents with unsaved changes are saved. A document you have not changed is never written.
- No message pops up; the status bar shows **Saved just now**.
- If a save is refused, Monstera shows why, and stops autosaving that document until you save it yourself.
