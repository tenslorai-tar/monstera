Each time it starts, Monstera checks whether a newer version is in the Microsoft Store. When there is one, **Update available** appears in the title bar. When you are up to date, nothing appears.

## Steps

1. When **Update available** appears at the top of the window, choose it.
2. The Microsoft Store opens on Monstera's page. Update from there.

## Good to know

- If a new version fixes a security problem, Monstera says so once, in a box titled **Important security update**. Choose **Open Microsoft Store** to update now, or **I understand** to close the box. Once you have chosen **I understand**, the box does not open again for that version; **Update available** stays in the title bar until you update.
- The Microsoft Store installs updates, never Monstera itself, and Windows normally installs them by itself.
- To stop the check, open **Settings**, choose **Updates**, and switch off **Check for new versions**. With it off, Monstera asks nothing at all and shows nothing.
- What the check sends: each time Monstera starts, it downloads a small file from monsterapdf.com that says which version is newest. Nothing about you or your documents is sent; like any website, it can see your internet address.
- If the file cannot be reached, nothing is shown, and Monstera checks again the next time it starts.
- To open the Store's updates page yourself, see "Get the newest version of Monstera".
