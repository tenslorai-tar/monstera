Monstera comes from the Microsoft Store, and the Store keeps it up to date. Monstera does not install updates itself.

## Steps

1. Open the **Help** menu and choose **Check for updates**.
2. The Microsoft Store opens on its updates page. Follow what it says there.

## Good to know

- Windows normally installs Store updates by itself. If you have turned that off in the Store, Monstera leaves your choice alone.
- To see which version you have, see "See the version and licences".
