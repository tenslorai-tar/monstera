Open any PDF on your computer to read, mark up or change it. Each document opens in its own tab, so you can have several open at once.

## Steps

1. On the start screen, choose **Open PDF…**. If a document is already open, in the rail choose **Home**, then **Open…** in the **File** group. You can also press **Ctrl+O**.
2. Pick the file in the window that opens and choose **Open**. To open several at once, select more than one file (hold **Ctrl** or **Shift**); each opens in its own tab.

![The start screen with the Open PDF… button and the line "or drop a PDF anywhere in this window"](screenshot:open-a-pdf-1)

To open by dragging:

1. Drag one or more PDFs from File Explorer onto the Monstera window. The window shows **Drop to open**.
2. Let go. Each file opens in its own tab, in the order you dropped them.

## Good to know

- Shortcut: **Ctrl+O**.
- Opening a document never runs anything inside it: no scripts, no automatic actions, no downloads, and no attached files are saved until you ask.
- If one of several files cannot be opened, Monstera names it and still opens the others.
- If a file has been moved, renamed or deleted, Monstera says it could not be opened. If you open a file that is already open, Monstera switches to its tab.
- If there is not enough room to open another document, close one first.
- Something dragged from a browser or another program that is not a file on this computer cannot be opened; drop a PDF from File Explorer instead.
- A password-protected PDF asks for its password: see "Open a password-protected PDF".
