Save a copy writes the document, with your changes, to a new file you choose. The document you are working on stays open from its original file.

## Steps

1. Open the **File** menu at the top of the window and choose **Save a copy…**.
2. Choose a folder and a file name, then **Save**.
3. A message says **Copy saved**.

![The File group's More menu open, showing Save copy…](screenshot:save-a-copy-1)

## Good to know

- This is a copy, not "Save as": the open document does not move to the new file. If it had unsaved changes, it still has them, and Monstera still asks about them when you close it.
- Monstera will not write over a file that is open in another tab.
