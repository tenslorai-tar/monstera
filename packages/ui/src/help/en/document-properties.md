A PDF can carry information about itself: its title, who wrote it, when it was made and which programs made it. Other PDF readers and search tools may show this information, so you may want to check it before you send a document.

## Steps

1. Open the **File** menu and choose **Document properties…**.
2. Change the **Title**, **Author**, **Subject** or **Keywords**.
3. To change a date, type it in **Created** or **Modified** as year, month, day and time, for example 2026-11-01 09:30.
4. Choose **Apply**.
5. Save the document to keep the change.

## What else the window shows

These cannot be changed here:

- **Made with**: the program the document was first made in, and **Saved as PDF by**: the program that wrote the PDF. A document that does not say reads **Not stated**.
- **PDF version**.
- **Pages**: how many, and the size of the first page in millimetres.
- **Size now**: the size of the document as it stands, with any changes you have not saved. It can differ from the size File Explorer shows.
- **Security**: whether the document is encrypted, and how, and anything its permissions do not allow.
- **Fonts**: the fonts the document names.

## Good to know

- The dates are the ones written inside the PDF. The file's dates in Windows are not changed.
- If Monstera cannot read a date you typed, it says so under the box and **Apply** stays off until the date is right.
- Empty a box to remove that item from the document.
- If you change nothing, **Apply** changes nothing in the document.
- Some PDFs hold this information in two places, and different readers show different ones. Monstera changes both, so every reader shows the same words.
- Undo with **Ctrl+Z**.
- To remove all of this information at once, see "Sanitize a document".
