If you do not know where a tool lives, search for it. The search box in the title bar lists every tool available right now, including ones that are not on the ribbon.

## Steps

1. Press **Ctrl+K**, or choose the **Search commands** box in the title bar.
2. Type part of the tool's name, for example "rotate" or "export".
3. Choose the tool from the list, or use the arrow keys and press **Enter**.

![The search list open over a document, with "rotate" typed and three rotate tools listed](screenshot:find-any-tool-1)

## Good to know

- Shortcut: **Ctrl+K**. Press **Esc**, **Ctrl+K** again, or click outside the list to close it.
- The list shows only tools that can be used right now. For example, page tools appear only while a document is open.
- It still works in the Focus layout, where the ribbon is hidden.
