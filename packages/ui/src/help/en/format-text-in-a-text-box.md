A text box and typed text can be set in a font, a size and a colour, in bold, italic, underlined or struck through, with the lines against the left, the middle or the right or justified, at a line spacing you choose, with padding inside the box and a coloured fill behind the words. A callout takes the font, size, colour and alignment only.

## Steps

1. Choose the **Select** tool and click the box.
2. Open the **Properties** tab. A **Text** section appears.
3. Under **Text**, choose a **Font**, type a **Font size** and press **Enter**, pick a **Text colour**, and choose **Left**, **Centre**, **Right** or **Justify** under **Align**. Tick **Bold**, **Italic**, **Underline** or **Strikethrough**, type a **Line spacing** or **Padding** and press **Enter**, and tick **Fill the box** to pick a **Fill colour**.
4. To make the box bigger or smaller, drag any of the eight small squares on its edge: a corner changes both sides, a side changes only that side.

![A text box selected, with the Text section in Properties](screenshot:format-text-in-a-text-box-1)

## Good to know

- The change applies to all the words in the box.
- **Use as default for new annotations** is ticked at first. The font and size you choose are then what the next text box starts in.
- **Sans**, **Serif** and **Mono** are the fonts every PDF reader has, so the words look the same wherever the file is opened.
- Monstera draws the styled box itself, in the fonts every PDF reader has, so it looks the same wherever the file is opened. The plain words are kept too, so search and other tools still find them.
- A box in a script those fonts cannot write (Hebrew, Arabic, Chinese, Japanese) is not restyled: the panel says so and the box is left exactly as it was.
- This changes how the words are shown. To change the words themselves, right-click the box and choose **Edit comment…**.
- Undo with **Ctrl+Z**. Each change is one step.
