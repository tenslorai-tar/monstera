A text box, a callout and typed text can each be set in a font, a size and a colour, with the lines against the left, the middle or the right.

## Steps

1. Choose the **Select** tool and click the box.
2. Open the **Properties** tab. A **Text** section appears.
3. Under **Text**, choose a **Font**, type a **Font size** and press **Enter**, pick a **Text colour**, and choose **Left**, **Centre** or **Right** under **Align**.
4. To make the box bigger or smaller, drag any of the eight small squares on its edge: a corner changes both sides, a side changes only that side.

![A text box selected, with the Text section in Properties](screenshot:format-text-in-a-text-box-1)

## Good to know

- The change applies to all the words in the box.
- **Use as default for new annotations** is ticked at first. The font and size you choose are then what the next text box starts in.
- **Sans**, **Serif** and **Mono** are the fonts every PDF reader has, so the words look the same wherever the file is opened.
- Bold, italic, a fill behind the words and line spacing are not offered, because PDF readers would not all show them.
- This changes how the words are shown. To change the words themselves, right-click the box and choose **Edit comment…**.
- Undo with **Ctrl+Z**. Each change is one step.
