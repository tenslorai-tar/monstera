If Monstera stops unexpectedly, the next time you start it the start screen lists the documents that were open so you can reopen them.

## Steps

1. Start Monstera.
2. Under **Monstera closed unexpectedly. These documents were open:**, choose **Reopen** beside each document you want back.

![The start screen's recovery offer listing two documents, each with a Reopen button](screenshot:reopen-after-a-crash-1)

## Good to know

- This reopens the files as they are on disk. Changes you had not saved before the crash are not brought back. Save often, or turn on autosave (see "Save automatically").
- The offer appears only after an unexpected close, never after you quit normally.
